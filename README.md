# Yen-Fu Chen 陳彥甫 — Personal Academic Portfolio

Personal academic website for Yen-Fu Chen, Associate Professor at Tatung University, Department of Digital Media Design.

## Research

Four research tracks: Design Thinking, Long-term Care & Dementia, Environment & Ecology, Human-Centered AI.

## Tech Stack

- React 18
- Vite
- Lucide React icons
- Deployed on Vercel

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
